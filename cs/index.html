Příprava

Zkouška DP-750 a co potřebujete

  • Prostředí pro laby: Azure Databricks workspace (Premium) v Azure subscription, případně Databricks Free Edition pro samostudium. Přesné požadavky uvádí každý lab v úvodu.
  • Oficiální laby: microsoftlearning.github.io — DP-750T00 (anglicky, krokové návody).
  • Learn kolekce kurzu: každá kapitola odkazuje na příslušný modul na Microsoft Learn — vhodné pro opakování po kurzu.
  • Zkouška DP-750 (study guide) má čtyři domény: Set up and configure an Azure Databricks environment (15–20 %) · Secure and govern Unity Catalog objects (15–20 %) · Prepare and process data (30–35 %) · Deploy and maintain data pipelines and workloads (30–35 %).
  • Kam dál: na kurz navazuje DP-600 — Microsoft Fabric Analytics Engineer; ochutnávku Fabricu najdete v kapitolách pod čarou.
